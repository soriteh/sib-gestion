# SIB Gestion

Application de gestion de Soritech Innov Business (SIB) : encaissements, caisse et banque, devis, factures, stock, formations, projets, ressources humaines et paie.

## Version de démonstration

Cette version est un fichier unique (`index.html`) hébergé avec GitHub Pages.

- Les données sont enregistrées dans le navigateur de chaque appareil : elles ne sont pas partagées entre utilisateurs.
- La page de connexion n'est pas une sécurité réelle : n'y saisissez pas de données réelles (clients, salaires).
- Pour une utilisation réelle avec plusieurs utilisateurs, il faut une version avec serveur et base de données PostgreSQL.

## Mettre à jour le site

Remplacez le fichier `index.html` du dépôt par la nouvelle version : le site se met à jour en quelques minutes.
